# Security overview

This fork uses user-owned credentials and local-first operation.

## Authentication and storage

- Google OAuth uses your own Desktop OAuth client.
- The loopback callback validates OAuth `state` and expires after five minutes.
- Google refresh tokens and Bing API keys are stored only in the OS keychain.
- There is no file fallback when secure storage is unavailable.
- Service-account files remain under your control and must be protected as
  secrets.

## Capability and network boundaries

- Mutating tools are disabled by default and require
  `SEARCH_CONSOLE_MCP_ENABLE_WRITE_TOOLS=true`.
- User-supplied schema URLs must be public HTTPS URLs; redirects, private
  networks, response size, and request duration are restricted.
- The fork performs no automatic update checks or installs and does not inject
  update notices into tool output.

## Data handling

There is no developer-operated backend or telemetry code in this fork. Tools
communicate with the selected Google, Bing, GA4, PageSpeed, or public website
endpoint. Tool inputs and results can still pass through your MCP client and
model provider.

See the repository [security policy](https://github.com/elmissouri16/search-console-mcp/blob/main/SECURITY.md)
for reporting and limitations.
